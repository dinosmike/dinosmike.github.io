ReFlow

A tiny, good-looking internet speed test for Windows — with a speedometer, a one-click test right from the system tray, and your country flag in the tray.

DownloadFree · Windows 10/11Source code on GitHub

Features

  • Speedometer and graph — live speed, maximum and average for the test
  • Test from the tray — speed digits right on the tray icon
  • Waits for the network and starts the test by itself
  • Country of your external IP in the main window and in the tray
  • Enhanced mode behind a VPN shows your real country
  • Test duration: 10 / 30 / 60 seconds or your own value
  • Starts with Windows, runs a test on startup
  • English and Russian
