ReIcon

A small Windows utility that converts images to ICO or PNG — with transparency, cropping, rounded corners, an outline and a live preview before saving.

DownloadFree · Windows 10/11Source code on GitHub

Features

  • Drag and drop or paste with Ctrl+V
  • Cropping and rounded corners with live preview
  • Outline with a color picker
  • Multi-size ICO: 256 / 64 / 48 / 32 / 16 px with transparency
  • PNG export at the original resolution
  • Input: PNG, JPEG, WebP, BMP, GIF, TIFF, TGA
  • English and Russian
