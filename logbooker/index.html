DCS Logbooker

An editor for the DCS World logbook.lua file: view and edit campaigns and mission history in a clear table, with an automatic backup on every save.

DownloadFree · Windows 10/11Source code on GitHub

Features

  • Reads large logbook.lua files
  • View and edit campaigns, mission history and the player profile
  • Add entries based on an existing one
  • Add the next mission with stage + 1 prefilled
  • Search and filter campaigns and history
  • Automatic backup before every save
