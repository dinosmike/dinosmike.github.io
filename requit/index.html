ReQuit

An auto shutdown app for Windows with a beautiful timer. It turns the PC off on a timer, at an exact time, or when CPU, GPU or network load drops — start a render or a download and go to sleep.

DownloadFree · Windows 10/11Source code on GitHub

Features

  • Beautiful borderless timer with animated digits
  • Shutdown or alarm mode
  • Delay before shutdown with a full-screen warning
  • Fires when CPU, GPU or internet load drops below a threshold
  • Can save a screenshot before shutdown
  • Exact clock time instead of a timer
  • Remaining time right on the tray icon
  • Russian and English
