ReIcon

Небольшая утилита для конвертации изображений в ICO или PNG — с поддержкой альфа-канала, обрезкой, скруглением углов, обводкой и предпросмотром перед сохранением.

СкачатьБесплатно · Windows 10/11Исходный код на GitHub

Возможности

  • Перетаскивание файла или вставка через Ctrl+V
  • Обрезка и скругление углов с предпросмотром
  • Обводка с выбором цвета
  • Многоразмерный ICO: 256 / 64 / 48 / 32 / 16 px с прозрачностью
  • Экспорт PNG в оригинальном разрешении
  • На входе: PNG, JPEG, WebP, BMP, GIF, TIFF, TGA
  • Русский и английский
