DCS Logbooker

Редактор файла logbook.lua авиасимулятора DCS World: показывает кампании и историю миссий в понятном виде и позволяет удобно их редактировать, с автоматическим бэкапом при каждом сохранении.

СкачатьБесплатно · Windows 10/11Исходный код на GitHub

Возможности

  • Читает большие файлы logbook.lua
  • Просмотр и редактирование кампаний, истории миссий и профиля игрока
  • Добавление записей по образцу
  • Добавление следующей миссии с готовым stage + 1
  • Поиск и фильтрация по кампаниям и истории
  • Автоматический бэкап перед каждым сохранением
