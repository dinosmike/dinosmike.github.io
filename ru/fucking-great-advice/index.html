Охуенный блять совет

Небольшое Windows-приложение для легендарного сервиса советов fucking-great-advice.ru: показывает советы текстовым оверлеем поверх рабочего стола — из трея, при запуске или по таймеру.

СкачатьБесплатно · Windows 10/11Исходный код на GitHub

Возможности

  • Клик по иконке в трее — новый совет
  • Оверлей поверх всех окон, исчезает при наведении мыши
  • Совет при запуске или по таймеру
  • Значок «offline», если сервис недоступен
