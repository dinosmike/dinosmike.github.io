ReSwitch

Быстрое переключение разрешения экрана по сохранённым профилям — прямо из трея, с автоматическим откатом, если новый режим не подошёл.

СкачатьБесплатно · Windows 10/11Исходный код на GitHub

Возможности

  • До 5 профилей: разрешение, частота и глубина цвета
  • Проверка, что дисплей поддерживает режим, перед сменой
  • Подтверждение с таймером и автоматический откат
  • Переключение профилей из меню трея
  • Популярные разрешения по правому клику
  • Темы: Тёмная, Светлая, Фуксия, Аквамарин
  • Совет дня по желанию
