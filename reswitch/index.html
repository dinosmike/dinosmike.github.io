ReSwitch

Quick screen resolution switching on Windows with saved profiles — right from the system tray, with a safety rollback if the new mode doesn't work.

DownloadFree · Windows 10/11Source code on GitHub

Features

  • Up to 5 profiles: resolution, refresh rate and color depth
  • Checks that the display supports the mode before switching
  • Confirmation with a countdown and automatic rollback
  • Switch profiles from the tray menu
  • Popular resolutions on a right click
  • Themes: Dark, Light, Fuchsia, Aquamarine
  • Optional tip of the day
